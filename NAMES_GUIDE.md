# Запуск Secure P2P Messenger с разными именами

## 🚀 Быстрый старт

### 1. Запуск с自定义 именем
```bash
./run_messenger.sh alice
```

### 2. Запуск другого пользователя
```bash
./run_messenger.sh bob
```

### 3. Запуск без имени (автоматическое)
```bash
.venv/bin/python back/web.py
# Имя будет сгенерировано автоматически: web_user_abc12345
```

## 📋 Поддерживаемые имена

Используйте любые имена на английском или русском:
- `alice`, `bob`, `charlie`
- `алиса`, `боб`, `виктор`
- `user1`, `user2`, `admin`

## 🔧 Альтернативный способ

Через переменную окружения:
```bash
export MESSENGER_USERNAME="alice"
.venv/bin/python back/web.py
```

## 📝 Как это работает

1. **Скрипт** устанавливает переменную окружения `MESSENGER_USERNAME`
2. **Веб-сервер** читает эту переменную при запуске
3. **Если переменная не задана** - генерируется уникальное имя
4. **Каждое имя** уникально в сети P2P

## ✅ Проверка

После запуска двух пользователей с разными именами:
- Откройте `http://127.0.0.1:5000` в двух браузерах
- Вы увидите друг друга в списке пиров
- Сообщения будут отображаться с правильных сторон

## 🐛 Проблемы?

Если имена одинаковые, сообщения могут отображаться некорректно.
Убедитесь, что у каждого пользователя уникальное имя!
