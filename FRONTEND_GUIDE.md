# 🚀 Запуск Secure P2P Messenger с именами через фронтенд

## 🎯 **Новый способ: Через браузер (рекомендуется)**

### 1. Запуск сервера
```bash
./smart_run.sh
```

### 2. Настройка имени
- Откройте: `http://127.0.0.1:5000/login`
- Введите имя: `alice`, `bob`, `viktor`
- Нажмите "Войти в чат"

### 3. Повторите для второго пользователя
- Второй терминал: `./smart_run.sh`
- Второй браузер: `http://127.0.0.1:5000/login`
- Введите другое имя: `bob`

## ⚡ **Быстрые варианты запуска**

### Способ 1: С именем в команде
```bash
./smart_run.sh alice
./smart_run.sh bob
```

### Способ 2: С переменной окружения
```bash
export MESSENGER_USERNAME="alice"
./smart_run.sh
```

### Способ 3: Прямой запуск
```bash
MESSENGER_USERNAME="charlie" .venv/bin/python back/web.py
```

## 🔧 **Как это работает**

1. **Первый запуск**: Если имя не указано → показывается страница логина
2. **Ввод имени**: Пользователь вводит имя в браузере
3. **Сохранение**: Имя сохраняется в localStorage
4. **Перезапуск**: Нужно перезапустить сервер с новым именем

## 📋 **Правила имен**

- ✅ Уникальные имена: `alice`, `bob`, `charlie`
- ✅ Русские имена: `алиса`, `боб`, `виктор`
- ✅ Длина: до 20 символов
- ✅ Символы: буквы, цифры, подчеркивание

## 🐛 **Если что-то не работает**

1. **Очистите localStorage**: F12 → Application → Local Storage → Clear
2. **Проверьте уникальность**: Убедитесь, что имена разные
3. **Перезапустите серверы**: Полностью закройте и запустите заново

## 🎉 **Результат**

После настройки:
- Сообщения отображаются с правильных сторон
- Имена отправителей видны в чате
- Нет дубликатов сообщений
- Удобный интерфейс для ввода имени
